# ⚽ Site de Time de Futebol

Página web desenvolvida para praticar a criação de sites utilizando HTML.

## 📌 Sobre o projeto

O projeto consiste em um site sobre um time de futebol, desenvolvido como exercício de estruturação de páginas e organização de conteúdo.

## 🛠️ Tecnologias

- HTML5

## 🎯 Objetivo

Praticar a criação de páginas web utilizando diferentes elementos HTML.

## 🚀 Como executar

Abra o arquivo HTML em um navegador.
